# Audit GEO calendrier-tempo.fr, 2026-09-29

Portée : lecture seule (app.py, templates/, blog.py, tempo_client.py, articles/). Site live non joignable : aucune citation LLM mesurée, aucune stat d'étude citée. Les mesures sont dans « À vérifier en ligne ». Références au format fichier:ligne.

## Synthèse

**Note : 5,5 / 10.** Accès crawlers 8/10, llms.txt 6/10, contenu citable 4/10, données structurées 6/10, cohérence 3/10.
Acquis : robots.txt très ouvert aux bots IA, llms.txt et llms-full.txt dynamiques, RSS en texte intégral, JSON-LD riche (FAQPage, Dataset, HowTo, Article), tarifs du 1er août 2026 exacts et cohérents partout (rouge HP 0,7295, ratio 4,4 vérifié, source arrêté du 29/07/2026 dans articles/_seo_rules.yaml:77). Le tarif rouge HP 0,7295 €/kWh est confirmé par la presse spécialisée (Selectra).
Faiblesse centrale : une IA qui lit le HTML brut ne peut pas répondre à la requête n°1 (« couleur Tempo aujourd'hui »), et elle trouve des faits contradictoires d'une page à l'autre.

**5 priorités**
1. Corriger l'erreur « samedi rouge possible » (dashboard.html:472-474) et centraliser les constantes (heure d'annonce, durée des alertes, chiffrement, ratio) dans un seul module Jinja.
2. Rendre en texte SSR la couleur du jour et de demain, les 15 jours et le calendrier de la saison (phrase de réponse directe datée, tableau, libellés complets), et publier des URL statiques par mois et par saison, avec les dates des 22 rouges de 2025-2026.
3. Publier une page Méthodologie et performance (métrique définie, échantillon, date), corriger les claims « 83 % », « seul site en France », « 900 000 foyers », et afficher l'identité de l'éditeur.
4. robots.txt : groupes explicites (Claude-SearchBot, Claude-User, Perplexity-User...) et /api/ traité de façon cohérente, généré par boucle ; llms.txt sans fausse date, avec /api/remaining et doc API ; llms-full.txt en Markdown brut.
5. Fraîcheur et JSON-LD : lastmod = updated_date, JSON-LD via `|tojson`, page API documentée (WebAPI + Dataset), refresh des articles au contexte figé sur la saison 2025-2026.

## Constats

### 1. Accès des crawlers IA (app.py:862-1089)

**[MAJEUR] Bots de recherche IA absents, ils tombent dans le groupe `*` qui bloque /api/.** Sont déclarés : GPTBot 913, ChatGPT-User 924, OAI-SearchBot 935, ClaudeBot 947, anthropic-ai 958, PerplexityBot 970, Google-Extended 982, GoogleOther 993, Applebot-Extended 1005, Meta-ExternalAgent 1017, cohere-ai 1029, Amazonbot 1041, Bytespider 1053, YouBot 1065, Diffbot 1077, bingbot 879, msnbot 895. Absents : Claude-SearchBot, Claude-User, Perplexity-User, CCBot, Applebot, Meta-ExternalFetcher, MistralAI-User, DuckAssistBot. Anthropic documente trois bots distincts, chacun avec son propre token ([SEJ](https://www.searchenginejournal.com/anthropics-claude-bots-make-robots-txt-decisions-more-granular/568253/)). Sans groupe dédié, Claude-SearchBot et Claude-User héritent de `*` (866-876) : pages OK, mais `Disallow: /api/`, donc l'API publique promise dans llms.txt leur est fermée. Correctif : boucle Python sur une liste `AI_SEARCH_BOTS` + `AI_TRAINING_BOTS`, chacun avec le même bloc ; ajouter au minimum Claude-SearchBot, Claude-User, Perplexity-User, Applebot, CCBot.

**[MAJEUR] Incohérence /api/ entre groupes.** Bing (887-892) autorise 3 endpoints puis `Disallow: /api/`. Les 13 groupes IA (913-1086) autorisent 3 endpoints mais n'ont aucun `Disallow: /api/` : tout /api/ leur est ouvert, dont `/api/indexnow/ping` (app.py:1395, GET public, paramètre `url` libre, déclenche un POST sortant vers IndexNow), `/api/calendrier-data`, `/api/history`. Le commentaire « API restreintes » (878) est faux pour les IA. Correctif : `Disallow: /api/` puis `Allow` explicite de today, tomorrow, predictions, remaining, history ; protéger `/api/indexnow/ping` par `verify_admin` (handoff @fullstack).

**[MINEUR] Commentaires inexacts et décisions non documentées.** « Google-Extended (Gemini, AI Overviews) » (981) : Google-Extended est un token de contrôle d'usage ; les AI Overviews suivent l'accès Googlebot (à reconfirmer dans la doc Google). Applebot-Extended (1005) est aussi un token. ChatGPT-User et Perplexity-User : leurs éditeurs indiquent qu'ils peuvent ignorer robots.txt pour les requêtes initiées par l'utilisateur ([OpenAI](https://developers.openai.com/api/docs/bots), [Perplexity](https://docs.perplexity.ai/docs/resources/perplexity-crawlers)) ; leurs lignes sont informatives. Entraînement autorisé pour GPTBot, ClaudeBot, Google-Extended, Meta, Bytespider, Diffbot... : décision business à consigner (ici cohérente avec l'objectif de visibilité, mais Bytespider et Diffbot n'apportent pas de citations). 17 blocs copiés-collés : risque de dérive.

**[MINEUR] Sitemap : `/feed.xml` (1136) listé comme URL de page ; /llms.txt et /llms-full.txt absents du sitemap (acceptable) mais aucun lien `<link rel="alternate">` ni mention dans le HTML.** Correctif : ajouter un lien discret en pied de page vers /llms.txt.

### 2. llms.txt et llms-full.txt (app.py:1174-1337)

Structure conforme à llmstxt.org (H1, blockquote, sections H2, « Optional »). Tarifs exacts (1223-1225, 1316-1318), calculs exacts (4,4x ; 14 € = 0,5641 x 25 kWh). Points à corriger :

**[CRITIQUE] Claim de précision non publiable en l'état (1198, 1239, llms-full 1328).** « Précision mesurée : 83 % sur J+2 à J+5 (backtesté sur 5 saisons 2019-2026) ». CLAUDE.md donne un backtest sur 2364 jours réels : F1 83,1 %, précision 85,4 %, rappel 81,0 %, exactitude 94,1 % : 83 % est un F1, pas une précision, et 2019-2026 couvre 7 saisons. Le chiffre n'est publié nulle part sur le site (a_propos.html:187-189 renvoie à une valeur JS, dashboard.html:528 affiche « chargement... »). Grille : vérifiabilité 1/3, précision 1/3, extractibilité 2/3 : à retravailler. Correctif : page Méthodologie (voir §3) et phrase llms : « Backtest sur N jours réels (période X), rappel des jours rouges Y %, précision Z %, mesuré le AAAA-MM-JJ ».

**[MAJEUR] Faux signal de fraîcheur.** « Dernière mise à jour : {today} » (1182, 1199 ; llms-full 1268, 1302) change chaque jour sans changement de contenu. Correctif : date = max(updated_date/publish_date des articles, date du barème tarifaire), ou supprimer la ligne.

J+15 » (1197) : superlatif invérifiable, filtré par les LLM. « 900 000 foyers sont abonnés à Tempo » (1207, aussi jours-rouges-tempo-guide.md:9) : aucune source. « Janvier concentre environ 35 % » (1240) contredit les fourchettes 5 à 8 jours (23 à 36 %) des articles. **[MAJEUR] Manques.** /api/remaining et /api/history absents de la liste (1216-1220) ; pas de page de doc API ; pas de licence ni de consigne d'attribution ; pas d'éditeur ni de contact ; pas de référence de l'arrêté (dispo dans _seo_rules.yaml:77) ; pas de mention de la saison courante 2026-2027 en première ligne.
