API Tempo EDF gratuite (JSON, sans clé)

Calendrier Tempo EDF met à disposition une API JSON publique, sans inscription ni clé, pour connaître la couleur Tempo du jour et de demain, les jours restants de la saison, nos prévisions à {{ facts.HORIZON_MAX_JOURS }} jours et l'historique des couleurs. Les couleurs officielles sont les {{ facts.SOURCE_COULEURS_PHRASE }} ; seule la couleur publiée par EDF fait foi.

/api/today et /api/tomorrow

Champs : status (ok ou unavailable), date (AAAA-MM-JJ), couleur (BLEU, BLANC ou ROUGE), code (1 = bleu, 2 = blanc, 3 = rouge). Tant qu'EDF n'a pas publié la couleur de demain, /api/tomorrow renvoie status: "unavailable" et un message. {{ facts.ANNONCE_J1 }}.

$ curl https://www.calendrier-tempo.fr/api/today
{"status": "ok", "date": "AAAA-MM-JJ", "couleur": "BLEU", "code": 1}

/api/remaining

Champs : remaining et totals (objets ROUGE / BLANC / BLEU), days_left_in_season, season_start, season_end, actuals_in_db et, quand ils sont disponibles, les compteurs relayés dans edf_official.

/api/predictions

Champs : predictions (liste), generated_at, cycle_id, accuracy. Chaque prévision contient date, couleur_predite, probabilite_bleu, probabilite_blanc, probabilite_rouge (entre 0 et 1), score_risque, temp_min_prevue, temp_max_prevue, raison, horizon et confirmed (true quand la couleur officielle EDF est connue : elle remplace alors la prévision).

/api/history

Paramètre days (1 à 365, 30 par défaut). Réponse : history, liste de {"date": "AAAA-MM-JJ", "couleur_reelle": "ROUGE"}, couleurs officielles uniquement.

Codes HTTP et bonnes pratiques

  • 200 : réponse normale (vérifiez le champ status).
  • 503 : service en cours de démarrage, réessayez quelques secondes plus tard.
  • 404 : endpoint inconnu.
  • Les réponses sont mises en cache 2 minutes : inutile d'interroger l'API plus souvent. Une requête par heure suffit pour la couleur du jour.
  • Aucune garantie de disponibilité : service gratuit et indépendant, non affilié à EDF ni à RTE.
