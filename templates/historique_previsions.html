Méthode

  • Données brutes, sans sélection : chaque jour dont EDF a publié la couleur figure dans le tableau, que notre prévision ait été juste ou non.
  • Prévision figée : pour chaque jour, nous gardons la dernière prévision émise 2, 3, 4 ou 5 jours avant, jamais recalculée après coup. Le délai se compte entre la date d'émission et le jour concerné : un calcul retardé après minuit compte pour le lendemain. Une prévision absente compte comme un jour manqué.
  • Pourcentages : affichés seulement à partir de {{ pct_min }} jours d'une même couleur (ou {{ pct_min }} alertes) pour un horizon donné. En dessous, l'échantillon est trop petit pour qu'un pourcentage ait un sens.
  • Algorithme : il évolue au fil de la saison ; chaque prévision est comparée telle qu'elle a été émise par la version alors en service.{% if start_date_label %} Historique tenu depuis le {{ start_date_label }}.{% endif %}
